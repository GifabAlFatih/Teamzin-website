TEAMZIN WEBSITE — UPDATED STARTER PROJECT

Isi folder:
- index.html  : struktur dan konten halaman
- style.css   : warna, layout, dan responsive design
- script.js   : menu mobile, copy world, dan tahun footer

CARA MENJALANKAN:
1. Ekstrak file ZIP.
2. Buka folder teamzin-website di VS Code.
3. Buka index.html dengan browser (klik dua kali dari File Explorer).
4. Untuk mengedit, ubah kode lalu simpan dan refresh browser.
